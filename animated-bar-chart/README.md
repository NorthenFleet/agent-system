# Five-bar animated chart

Seven-second Remotion composition, 1280 × 800 at 30 fps. Five sample scores rise in sequence with synchronized value counters, followed by a hold for readability.

```sh
npm install
npm run dev
```

Open the Studio URL printed by the command and select `FiveBars`.
Edit the five `Bar` nodes in `src/Root.tsx` to change labels, values (0–100), colors, and delay frames.
