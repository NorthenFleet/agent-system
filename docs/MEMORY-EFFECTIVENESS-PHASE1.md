# 真实记忆效果第一阶段：基线与证据链

## 阶段结论

第一阶段已建立可复现的真实统一库快照基线和线上效果证据链，但**记忆效果尚未达标，也不具备进入下一次检索切流的条件**。

本阶段没有新增发布治理能力，没有自动激活机器生成标签，没有修改检索排序配置。评测所用 Context Pack 均为 `persist=false`，不会污染在线检索记录。

## 交付范围

### 1. 离线效果基线

- 数据源：`3021-unified-memory` 当前活跃权威记录；
- 权威来源：10 条用户事实、3 条当前用户项目记忆、2 条当前用户智能体记忆；
- 样本数：80；
- 问法：每条来源最多 5 种问法，另含用户、项目、智能体作用域隔离反例；
- 隐私：数据集不复制记忆正文，只保存查询、来源引用和正文快照哈希；
- 标签状态：全部为 `provisional`，必须经人工核验后才能成为正式真值；
- 自动切流：始终关闭。

可复现执行命令：

```bash
backend/venv/bin/python backend/scripts/memory_effectiveness_baseline.py \
  --owner-user-id 1 \
  --target-cases 80 \
  --dataset-output backend/evals/memory_effectiveness_phase1.json \
  --report-output docs/MEMORY-EFFECTIVENESS-PHASE1-BASELINE.json \
  --summary-only
```

脚本在效果门禁未通过时返回非零状态，这是预期行为，不代表脚本执行失败。

### 2. 在线真实效果证据链

每个持久化 Context Pack 会自动追加 `selected` 事件。任务消费者可继续报告：

1. `used`：哪些被选记忆实际进入了推理或操作；
2. `task_outcome`：任务成功、部分成功或失败；
3. `correction`：用户纠正、拒绝或要求遗忘。

接口：

```http
POST /api/v3/context/packs/{pack_id}/effect
GET  /api/v3/context/effectiveness/summary
```

效果事件只保存用户、任务和来源引用的 SHA-256 指纹以及白名单标量元数据，不保存查询正文、记忆正文或自由文本反馈。事件采用幂等键追加，不能伪造 Context Pack 之外的来源，也不能跨用户提交。

指挥中心主链路已接入自动上报：规划、步骤执行和最终评估在实际渲染 Context Pack 时记录 `used`，并在计划保存、步骤验收和任务终评后记录 `task_outcome`。上报失败只写错误日志，不会改变任务执行状态。用户纠正仍通过显式 `correction` 接口记录，避免系统自行猜测用户意图。

## 2026-09-18 基线结果

| 指标 | 当前值 | 目标/判定 |
| --- | ---: | --- |
| 样本数 | 80 | 达到临时基线规模 |
| 用例通过率 | 68.75% | 未设为正式门禁 |
| Recall | 66.67% | 未达标 |
| 重要记忆 Recall | 83.33% | 目标 ≥ 90%，未达标 |
| Top-5 命中率 | 26.67% | 诊断指标，明显偏低 |
| Precision@5 | 暂不可评估 | 缺少完整 Top-5 相关性标注 |
| 禁止来源命中 | 0 | 当前覆盖范围内通过 |
| 跨作用域泄漏 | 0 | 当前覆盖范围内通过 |
| 检索降级样本 | 0 | 通过 |
| 人工验证样本 | 0/80 | 未达标 |

Precision@5 没有使用单一期望来源强行计算。当前标签只说明“这个来源应该出现”和“这些来源禁止出现”，没有对 Top-5 其余来源逐项判定相关性；在完整标注前给出精确率会产生错误结论。

## 首要问题归因

25 个失败样本全部是召回失败：

- 项目记忆：15 个失败；
- 智能体记忆：10 个失败；
- 五类问法各失败 5 个，说明问题不是某一种模板措辞造成的。

用户档案中的 `critical/high` 事实当前即使与查询没有词项重合也会全部进入候选。当前用户恰有 10 条高重要度档案事实，容易占满 `limit=10` 的结果窗口，把项目记忆和智能体记忆挤出最终 Context Pack。这是第一阶段发现的主要检索结构问题，下一阶段应优先修复“全量高重要度注入导致的作用域记忆淹没”，而不是继续扩展发布基础设施。

## 尚未覆盖的真实生命周期场景

当前统一库没有可直接作为真值使用的完整样本，因此以下场景仍被门禁明确阻断：

- 更新后新值生效、旧值不再召回；
- 冲突记忆按权威性和时效决胜；
- 到期记忆不再召回；
- 遗忘后权威库、向量和图投影均无残留；
- 无相关记忆时主动克制，而不是硬返回内容；
- 完整 Top-5 相关性标注。

这些场景应在第二阶段使用隔离的生命周期测试夹具和人工复核数据建立，不能用不存在的来源做“天然通过”的假测试。

## 阶段门禁

当前 `effectiveness_gate.ready=false`，阻断项为：

- 重要记忆 Recall 未达到 90%；
- Precision@5 尚无完整标注，无法评估；
- 80 条样本尚未人工验证；
- 更新、冲突、到期、遗忘和克制场景未覆盖。

下一阶段的中心任务是生命周期权威账本与受控场景夹具，同时先修复本阶段已经证实的检索窗口淹没问题，并用同一基线回归验证。
