# DR4 工具调用控制与持久化回执

日期：2026-10-08；状态：核心实现与本地验证完成，生产默认关闭。

上接 [架构方案](DECISION-ROUTING-ARCHITECTURE.md) 与 [DR3](DECISION-ROUTING-PHASE-3.md)。本批只覆盖 `isolated-code-v1` 的文件工具调用；普通 OpenClaw 步骤、顾问和确定性执行器保持各自的执行契约。

## 1. 扩展能力与选型

本机 OpenClaw 2026.8.2 提供工具前后钩子，但仅依赖钩子无法保证插件加载失败时仍能阻止原生工具。本批采用专用工具适配器：临时执行配置仅允许 `dr4_read`、`dr4_list`、`dr4_write`、`dr4_edit`，全部操作交给后端控制器；不开放原生文件工具、shell、浏览器、网络或子代理工具。实际安装版本的插件运行时检查已加载四个工具，无诊断错误；其工具策略管线验证插件缺失时可用工具数为零。

插件位于 `integrations/openclaw/mission-tool-control`。每个步骤尝试创建独立 Unix socket 与随机认证令牌，目录和 socket 限制本机权限，凭证仅进入临时配置，不进入模型提示词。执行器结束后关闭连接并清理 socket。

## 2. 调用顺序与权威

1. 模型发起专用工具调用，插件携带调用 ID、参数和认证令牌请求本地控制器。
2. 后端锁定步骤，检查 running 状态、当前计划、Mission 状态、执行器、未过期租约和尝试号；从服务端已保存的工作区回执读取根目录。
3. 检查工具白名单、路径、参数和调用预算，提交 `tool_intent` 后才允许文件操作。
4. 在第二个事务重新检查执行权威，执行有界文件操作，写入 `tool_receipt`，再返回结果。
5. Worker 汇总本次尝试的意图、回执和拒绝记录。无回执、拒绝、未知副作用或未闭合意图均不能生成通过的代码候选。

复用 Mission 事件表，无新数据库迁移。事件携带步骤、计划版本、尝试、调用 ID、参数摘要、资源路径和策略版本；文件内容不写入事件。调用 ID 重复时记录拒绝且不再次执行，预算耗尽记录拒绝。文件操作与数据库提交不是原子事务：写入后进程崩溃会留下未闭合意图，禁止自动重放，以待核验状态阻止候选通过。模型自述成功不能覆盖这些服务端事实。

## 3. 文件与预算边界

- 每次尝试最多 64 个调用意图，单文件上限 128 KiB，目录列表最多 512 项。
- 仅接受工作树内相对路径，拒绝绝对路径、父目录逃逸、`.git` 和符号链接；通过目录文件描述符逐段打开，拒绝硬链接和非普通文件。
- 写入只在已有父目录中创建或替换文件；编辑要求旧文本唯一匹配。暂不提供 mkdir、删除、执行测试或安装依赖工具。
- 写入/编辑异常保守标记未知副作用，阻止候选通过。只读失败经传输返回拒绝也会阻止本次候选通过。
- 这不是对恶意同宿主进程的操作系统沙箱；宿主与插件代码仍是可信计算基础。隔离候选仍需独立集成审批和合并后验收。

## 4. 配置与展示

`COMMAND_CENTER_TOOL_CONTROL_ENABLED=false` 默认关闭。启用时同时需要 DR3 的工作区开关、操作员维护的仓库映射、固定基线和受支持的 worker 模型配置。仅显式 `isolated-code-v1` 生效；无法创建控制器或加载可用工具不会退回原生写文件工具。

步骤结果新增 `tool_control` 摘要：执行控制状态、调用数、回执数、拒绝数、未闭合数、未知副作用数和是否通过。指挥中心展示“工具调用控制”及回执状态。原有审批、租约、WorkRun、证据和候选 Git 校验继续生效。
