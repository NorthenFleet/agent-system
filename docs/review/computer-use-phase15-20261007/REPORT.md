# 第十五阶段：交付异常的前端反馈与重新交付草稿

日期：2026-10-07。源码修改与隔离 Computer Use 验收完成。本阶段构建到 /private/tmp/agent-system-phase15-dist，未替换生产 frontend-v2/dist，也未重启生产服务。

## 问题与修改

原页面下载失败时忽略后端原因，并可能同时出现通用请求失败提示。现在下载请求抑制一般全局报错，由对应产物区域解析 Blob 格式的 JSON 错误，持续显示具体原因。会话失效和权限不足仍遵循全局认证处理。下载期间阻止重复点击，成功重试后清除该产物的错误。

产物区域增加可展开的原路径和登记 SHA256，明确区分历史任务完成与文件当前可下载。失败后可以准备重新交付任务，自动填写原任务 ID、产物 ID、路径、哈希、失败原因，以及保留旧证据、独立路径交付和审批要求。该按钮只填写既有创建任务表单，不自动提交；表单已有标题或目标时按钮禁用，避免覆盖草稿。

## Computer Use 结果

使用 localhost:3045 隔离服务器和真实前端构建。任务详情来自第十三阶段已完成任务的副本，替换任务标识和产物为本阶段样本；不连接生产数据库、不启动 worker、不提交新任务。下载调用生产路由函数和生产文件校验器，任务读取和认证是测试夹具。

| 操作 | 结果 |
| --- | --- |
| 下载原登记文件 | 200，响应哈希匹配登记 SHA256 |
| 保留原件后修改文件，再点击下载 | 409，页面持续显示“文件已变化，与该任务登记的版本不一致” |
| 展开原交付记录 | 原路径和原哈希可见，历史状态未被篡改 |
| 点击页面刷新 | 错误信息仍在 |
| 整页重载后再次下载 | 再次 409，具体原因一致 |
| 点击准备重新交付任务 | 项目、文档类型、标题及带证据引用的目标正确填入，提示尚未启动任务 |
| 已有草稿时 | 重新交付按钮禁用，草稿保留 |
| 移走测试文件后下载 | 409，显示“文件不可读取” |
| 将保留原件复制回测试路径后重试 | 200，错误区域消失，已有任务草稿仍保留 |
