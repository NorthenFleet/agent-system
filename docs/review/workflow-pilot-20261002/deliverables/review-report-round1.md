**要求**: 为每个环节给出具体的追溯查询方式（如 SQL 查询、API 调用路径），使验证者可独立复现。

### R-3: 补充并发与数据一致性异常场景

**问题**: 缺少并发步骤认领冲突、产物提交部分写入中断、智能体崩溃后步骤状态恢复等场景。
